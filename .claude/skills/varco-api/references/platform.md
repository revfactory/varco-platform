## [가이드] introduction

### VARCO API 플랫폼 소개
#### 상상력을 AI 기술로 연결하는 VARCO API 솔루션 

단 한 번의 연동으로 텍스트, 이미지, 오디오, 데이터 처리 등 다양한 AI 기능을 손쉽게 활용하세요. 개발자는 API문서와 예제를 통해 빠르게 통합할 수 있으며, 모든 호출 내역과 크레딧 사용을 한 눈에 관리할 수 있습니다. 지금 바로 API를 호출하고, 당신의 제품에 AI 기능을 더해보세요.

### Document
이 문서는 VARCO API Platform을 효율적으로 활용하기 위한 기술 가이드입니다.
현재는 각 API 서비스의 크레딧 단가 및 기본 정보를 제공합니다.
향후 서비스별 기능 설명, 요청 및 응답 구조, 예제 코드, 통합 절차 등을 포함하여 AI 기능을 실제 서비스에 적용할 수 있도록 단계별 문서를 확장할  예정입니다.

포함 내용
- 연동 절차: API를 호출하고 응답을 처리하는 기본 흐름
- 인증 가이드: API Key 및 인증 헤더 구성 방법
- 요청/응답 구조: 주요 엔드포인트, 파라미터, 응답 포맷
- 예제 코드: 언어별 API 호출 예시
- 오류 처리: 주요 오류 코드와 대응 방법

### 워크스페이스 생성
협업을 위해 [공용 워크스페이스] 를 생성하여 멤버를 초대해보세요.

- 개인 워크스페이스 : 최초 로그인 시 필수로 생성되는 워크스페이스입니다. 개인의 API 활용을 위한 용도로만 활용할 수 있도록 멤버 초대 기능은 지원하지 않습니다.

- 공용 워크스페이스 : 협업을 위해 생성할 수 있는 공용 워크스페이스이며, 멤버 초대 기능을 지원합니다.

### 크레딧 구매
크레딧은 API 키를 호출하기 위해 필요한 플랫폼 내 재화입니다. 크레딧 구매는 홈페이지 상단 GNB 내 [상품 안내] or 홈페이지 사이드 바 내 [결제] 페이지 내 [크레딧 구매하기] 경로를 통해 구입 가능합니다.
크레딧 구매는 개인, 공용 워크스페이스에서 둘다 구매가 가능하며, 구매 시 해당 워크스페이스 오너 권한이여야만 구매할 수 있습니다.
- 워크스페이스 생성 또는 초대받기 완료 → 크레딧 구매를 진행할 워크스페이스 내 오너 권한 확인 → 상품 안내 페이지 진입 → 구매할 크레딧 상품 내 [구매하기] 버튼 클릭 → 팝업된 워크스페이스 선택 모달창을 통해 크레딧 구매 워크스페이스 지정 → 결제창 진입 및 결제 완료

### API 호출
API 호출은 사용자가 VARCO API Platform에 요청(Request)을 보내고, 플랫폼이 결과(Response)를 반환하는 과정을 의미합니다. 해당 API가 소속된 워크스페이스 내 크레딧이 부족할 경우 API 키 호출이 실패할 수 있습니다.

### 크레딧 차감
VARCO API Platform은 크레딧 기반 과금 시스템으로 운영됩니다. 즉, API를 호출할 때마다 해당 호출의 처리량·모델·요청 크기 등에 따라 크레딧이 자동으로 차감됩니다.
- VARCO API Platform에서 제공하는 모든 API 서비스의 크레딧 비용은 [Pricing]( https://api.varco.ai/ko/docs/pricing?version=0)에서 확인하실 수 있습니다.

## [가이드] chatbot-overview

VARCO Chat은 자연스러운 대화를 통해 고객 상담·서비스 안내 등 다양한 업무 자동화를 가능하게 하는 챗봇 서비스를 제공합니다. 또한 챗봇이 사용할 지식을 관리하고 유지보수하기 위한 CMS(Content Management System) 도구를 함께 제공하여 챗봇 운영을 효율적으로 지원합니다.

![챗봇 화면](https://cdn-api.varco.ai/document/d7b27955d0b24b7196438bcee8d6c23e.png)

### [주요 기능]
**FAQ**

자주 묻는 질문에 대해 미리 준비된 정확한 답변을 자동으로 제공하는 기능입니다. 사용자가 자주 문의하는 질문에 대해 일관되고 정확한 답변을 제공하여 고객 상담 효율을 높입니다. 

게임 서비스에서는 주로 게임 설치 방법, 주요 운영 정책, 이벤트 안내 등에 활용되며, 사내 서비스에서는 회사 내규, 업무 프로세스, 제도 안내 등을 FAQ로 구성하여 활용할 수 있습니다.

**사용자 데이터 마트**
빠른 문의 해결을 위해 다양한 운영 업무 유형에 맞춘 사용자 로그 처리 ETL 파이프라인을 구축하고 있습니다. 사용자가 아이템 복구, 접속 이력 조회, 제재 이력 확인 등의 문의를 요청하면, 사용자 데이터 마트를 통해 즉시 필요한 정보를 제공합니다.

예를 들어, 잃어버린 아이템 정보나 접속 기록 등을 실시간으로 조회하여 제공하고, 아이템 복구와 같이 운영진의 직접적인 의사 결정이 필요한 경우에는 관련 데이터를 종합적으로 제공하여 의사 결정을 지원합니다. 이를 통해 게임 운영 업무의 생산성을 크게 향상시킵니다.

**Retrieval Augmented Generation (RAG)**

![생성 요약](https://cdn-api.varco.ai/document/1c47df47c55d4f5f81598a8742c0c37a.png)

게시판, 뉴스, 공지사항 등 다양한 데이터 소스를 크롤링하여 수집하는 기능을 제공합니다. 수집된 문서들을 벡터 데이터베이스에 저장하고, 사용자의 질문과 관련된 문서를 검색하여 컨텍스트로 활용합니다. 이를 통해 최신 정보를 반영한 정확하고 맥락에 맞는 답변을 생성할 수 있습니다.

RAG 기술을 활용하여 단순히 학습된 지식에 의존하지 않고, 실시간으로 업데이트되는 최신 정보를 바탕으로 답변을 제공하므로, 게임 업데이트, 이벤트 정보, 공지사항 등이 변경되어도 별도의 모델 재학습 없이 최신 정보를 제공할 수 있습니다.

**Builder**

![챗봇 빌더](https://cdn-api.varco.ai/document/f527474b46b04ac296de45b08e56e85e.png)

챗봇 빌더는 FAQ 및 지식 베이스를 관리하고, 챗봇을 구성하는 UI의 Asset을 관리하는 CMS 도구입니다. 직관적인 인터페이스를 통해 비개발자도 쉽게 챗봇을 구성하고 관리할 수 있습니다.

주요 기능:
- **지식 관리**: FAQ, 대화 시나리오, 응답 템플릿 등을 체계적으로 관리
- **UI Asset 관리**: 챗봇 인터페이스의 디자인 요소, 버튼, 카드 레이아웃 등을 관리
- **크롤러 관리**: 다양한 데이터 소스에 대한 크롤러 설정 및 스케줄링 관리
- **대시보드**: 챗봇 사용 현황, 대화 통계, 사용자 만족도 등 실시간 모니터링

### [활용 시나리오]
**사내 서비스**
외부 생성형 API를 사용할 수 없는 보안이 중요한 환경에서, 회사의 주요 문서들을 기반으로 한 챗봇을 구축하고 관리하는 데 활용할 수 있습니다. 

예를 들어, 회사 내규, 업무 매뉴얼, 제도 안내, IT 지원 가이드 등을 지식 베이스로 구축하여 직원들이 자주 묻는 질문에 대해 24시간 자동으로 답변을 제공할 수 있습니다. 이를 통해 인사팀, IT 지원팀 등의 업무 부담을 줄이고 응답 속도를 향상시킬 수 있습니다.

**다양한 도메인의 고객 대응 서비스**
현재는 게임 도메인을 중심으로 챗봇 서비스가 구축되어 있지만, 지식 베이스를 교체하여 게임 이외의 다양한 도메인에도 적용할 수 있습니다.

- **전자상거래**: 상품 문의, 배송 조회, 반품/교환 안내 등
- **금융 서비스**: 상품 안내, 계좌 조회, 대출 상담 등
- **교육**: 강의 안내, 수강 신청, 학습 자료 제공 등
- **의료/헬스케어**: 진료 예약, 증상 안내, 병원 정보 제공 등

각 도메인에 맞는 지식 베이스를 구축하고, 도메인 특성에 맞게 챗봇의 톤앤매너와 응답 방식을 커스터마이징하여 고객 만족도를 높일 수 있습니다.

## [가이드] gentlewords-overview

Gentle Words는 AI 기술 기반의 텍스트 내 유해 표현을 감지하고 차단하는 시스템입니다.
실시간 채팅, 커뮤니티 게시글, 사용자 닉네임 생성 과정 등에서 부적절한 표현을 걸러내어 깨끗하고 안전한 서비스 환경을 만듭니다.

### [주요 기능]
**스팸 필터링**
스팸 메시지가 채팅 환경을 방해하지 않도록, 모델이 메시지를 분석해 광고성 스팸을 비롯하여 서비스에서 제한하고 있는 메세지의 스팸 여부를 자동으로 판단합니다 관리도구에서 직접 등록한 스팸 패턴은 물론, 기호나 유사 문자로 우회한 표현까지 탐지합니다.

**예시**
 - 등록 패턴: gold. com
 - 감지되는 표현: GΟLD, ℃θ/N

**금칙어 필터링**
**금칙어**
채팅에서 사용을 제한하고 싶은 단어를 등록하시면, 다양한 방식으로 자동 감지하여 차단합니다.

- 완전일치: 단어 전체가 동일하게 입력되는 경우 필터링합니다.

- 부분일치: 단어 안에 금칙어가 일부 포함된 경우 필터링합니다.

- 시작일치: 금칙어로 시작하는 표현을 필터링합니다.

**예외처리단어**
금칙어를 포함하고 있지만 일반적으로 문제없이 사용되는 단어는 예외단어로 등록하여 차단 대상에서 제외할 수 있습니다.

**예시 – 완전일치** 
- 금칙어: apple
	- 출력: I bought an ***** today.
	- 원문: I bought an apple today.
- 예외처리단어: pineapple
	- 출력(원문과 동일): I like pineapple on pizza.

**예시 – 부분일치**
- 금칙어: rock
	- 출력: He is a ****star!
	- 원문: He is a rockstar!
- 예외처리단어: rocket
	- 출력(원문과 동일): The rocket finally launched into space.

## [레퍼런스] authentication

API 호출 시, OPENAPI_KEY를 통해 인증이 이루어집니다.
이 키는 사용자에게 발급되며, 애플리케이션이 API를 호출할 때 요청 헤더에 포함되어 사용자를 식별합니다.

#### 인증 방식

모든 요청 헤더에 아래와 같이 OPENAPI_KEY를 포함해야 합니다.

##### Request Example
```bash
curl --location 'https://openapi.ai.nc.com/mt/chat-content/v1/translate' \
--header 'OPENAPI_KEY: <OPENAPI_KEY>' \
--header 'Content-Type: application/json' \
--data '{
  "TID": "00000000-0000-0000-0000-00000000000",
  "game_code": "linw",
  "provider": "chat",
  "source_lang": "en",
  "source_text": "help help",
  "target_lang": "ko"
}
```
OPENAPI_KEY가 누락되거나 잘못된 경우, HTTP 401 Unauthorized 응답이 반환됩니다.

```bash
{
    "message": "Unauthorized",
    "request_id": "b6dbdd2b6153057bcd3b5b3ae8cdea66"
}
```

#### 주의사항

OPENAPI_KEY는 비공개 자격 증명 정보이므로 외부에 노출되어서는 안 됩니다.

키가 유출될 경우, 타인이 API를 호출하거나 크레딧을 무단 사용할 수 있습니다.

GitHub, Notion, Slack, 프론트엔드 코드 등에 하드코딩하거나 공유하지 마세요.

분실 또는 유출이 의심되는 경우, 즉시 기존 키를 폐기하고 새로운 키를 발급받으십시오.

일부 서비스에서는 OPENAPI_KEY를 통해 API 서비스 접근 권한(Role) 또는 Rate Limit, Credit 사용 한도가 자동으로 결정될 수 있습니다.

테스트 및 운영 환경에서는 서로 다른 Key를 사용하는 것을 권장합니다.

사용하지 않는 키는 삭제하여 보안을 유지하십시오.
