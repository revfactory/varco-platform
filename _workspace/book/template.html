일러두기
  1. 이 책자는 VARCO API Platform 사이트(api.varco.ai)에 공개된 한국어 문서를 2026년 9월 28일에 내려받아 엮은 참고용 사본입니다. 제1부에 도큐먼트 {{N_DOCS}}편, 제2부에 API 레퍼런스 {{N_REF}}편을 실었습니다.
  2. 원문은 그 뒤에 바뀌었을 수 있습니다. 최신 내용은 각 장 제목 아래에 적은 원문 주소에서 확인하시기 바랍니다.
  3. 순서와 묶음은 사이트 왼쪽 메뉴를 따랐고, 메뉴의 묶음 이름은 각 장 맨 위에 적었습니다. 도큐먼트에서 서비스별로 한 번 더 묶인 문서는 장 제목 앞에 서비스 이름을 붙였습니다. 예를 들어 Sound 묶음의 Conversion 문서는 Sound · Conversion으로 적었습니다.
  4. 도큐먼트 장 끝의 요금표는 사이트가 문서와 함께 보여 주는 요금 정보를 같은 날 기준으로 옮긴 것입니다.
  5. 오디오와 영상은 종이에서 재생할 수 없어 링크로 바꿨습니다. 영상은 한 장면을 캡처해 미리보기로 넣었습니다. PDF 뷰어에서 링크나 미리보기를 누르면 원본 파일이 열립니다.
  6. 문서끼리 가리키는 링크는 이 책자 안의 해당 장으로 이동합니다. 이 책자에 싣지 않은 페이지로 가는 링크는 사이트로 연결됩니다.
  7. 원문의 표기와 오탈자는 고치지 않았습니다.
